# sdlc Config: Global User

You are writing tier 1, the global user file. Read
`skills/lib/sdlc-config.md` for its path, its keys, and the writer
steps, and run those steps against that file. That contract is the only
statement of them; this skill does not restate them.

Tier 1 is the lowest tier, so every value shown as "resolves to" before
a question is the key's default.

The file lives outside every repository. Write that one file and
nothing else.
